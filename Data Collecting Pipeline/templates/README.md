# Workbook template authority

For a new Hong Kong Main Board cohort, start from `HKIPO-MB-template-final.xlsx`. This is the repository's authoritative Main Board workbook template and is the one to compare against `schema/fields.json` and `schema/allot_fields.json`.

`HKIPO-MB-template-students.xlsx` is retained for student collection exercises. `HKIPO-GEM-template-students.xlsx` is for GEM listings. Do not create a working cohort from an Excel “Copy of …” file; use the repository template and record the resulting cohort workbook in its own pipeline config.
