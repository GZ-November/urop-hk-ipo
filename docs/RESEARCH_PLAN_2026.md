# 2026 IPO研究计划：从基础统计到三个可深入的问题

更新：2026-10-02；研究输入和行情截止2026-09-30。按用户要求重新选题：先把市场和数据看清楚，再深入少数问题。现有复杂分析作为探索性参考，不决定近期选题，也不替代基础统计。上一版广泛并行的计划保存在 [归档](archive/pre-basics-replan/RESEARCH_PLAN_2026.md)。

## 研究范围与近期目标

主样本为2026-01-02至2026-09-30上市的113家主板普通IPO（Q1 38、Q2 45、Q3 30）。保留当前仅2026年的研究边界，暂不为了做制度检验扩成多年样本。原始价格、HDR计量及已经完成的证据修复沿用现有研究输入。

近期目标是完成一份能清楚回答以下问题的基础统计报告：

1. 2026新股市场有什么特征？平均IPO与典型IPO是否不同？
2. 什么类型的新股更受认购、首日表现更好？这些差异是否只是季度或规模不同？
3. 首日上涨能否转化成散户申请资金的收益？

完成全景之后先深入 **A：认购热度与首日表现** 和 **B：散户获配收益**。**C：A+H发行折价** 是第三个可独立推进的候选；若B的配售表试采集不顺，则先推进C。最多同时推进两条主线。

## 第一步：基础statistical analysis

### 1. 先做覆盖与口径表

每个字段列出总体N、非缺失N、未知／缺失N、取值种类和季度覆盖。覆盖只是存储中有值，不等于完成独立来源核验。将四种缺口分开：未采集、未披露／证据不足、不适用、观察窗口未成熟。

[基础统计入口](../analysis/basic_statistics_2026.py)已生成 [基础报告](../analysis/out/basic_statistics/basic_statistics.md) 和202字段覆盖表。该模块只运行描述统计、分组和简单相关，不运行回归或显著性检验。

### 2. 一套共同的基础表和图

| 工件 | 问题／内容 | 第一轮方法 |
|---|---|---|
| 表1：样本构成 | 每月／季度IPO数量、行业、上市路径、募资 | 计数、占比；小组同时显示N |
| 表2：核心变量 | 首日收益、发售规模、企业年龄、认购倍数、申请人数、基石比例 | 非缺失N、均值、中位数、标准差、25/75分位、最小最大值 |
| 表3：首日收益分布 | 破发、平收、大幅上涨；平均数是否被少数赢家拉高 | 破发率、分位数、等权与基础发售金额加权收益、极端值对照 |
| 表4：简单分组比较 | 季度、A+H／非A+H、上市路径、规模三组、认购热度三组 | 每组均值、中位数、破发率和N；阶段1先不加显著性星号 |
| 表5：相关关系 | 首日收益与认购、规模、年龄、基石份额的关系 | 散点和Spearman秩相关；每对变量单独列有效N |
| 表6：短期上市后收益 | 从首日收盘买入，5／20个交易日后表现如何 | 完整窗口的收益分布、正收益比例、同期指数对照；逐期限列N |
| 图1—4 | IPO月度数量、首日收益直方图、季度／路径箱线图、认购倍数与首日收益散点图 | 认购倍数和规模可用对数轴；保留原始单位说明 |

当前基础模块已产出覆盖表、描述统计、季度／月份／路径／认购三组及相关表；行业／规模分组、图和短期收益表是下一次执行的具体交付。现有Module A等可复用，但不把里面的复杂检验一并塞进初稿。

财务分析先用盈利／亏损、同期间利润率等；人民币、美元和港元财务金额不能直接混合比较。基础发售金额按P0×基础发售证券数计算，不等同于含绿鞋募资或发行人净所得。固定价格发售不适用区间修价，不能把其0当成一次“没有上修”的可比观察。

### 3. 第一轮读表后再选择深入程度

先检查极端发行人、缺失集中在哪个季度和小组、均值与中位数是否矛盾。分组同时按季度或A+H分开看，避免把组别构成差异解释为经济机制。数据清楚后才加少量均值／分布差异检验和置信区间；有多项比较时一起报告，不能只挑显著结果。

第一阶段不需要新增数据才能开始。优先修正核心字段的小缺口，而不是先补齐全部202列。

## 第二步：选择三个问题中的两个深入

### A. 认购热度高的新股，首日表现是否更好？——先做，现有数据足够

**问题**：认购倍数／申请人数与首日收益、破发率有什么关系？更热门是否主要因为发行规模较小？

**已有数据**：113家首日收益、认购倍数、申请人数、最终公开发售股数、基础发售股数、上市月份及上市路径。均有存储值。

**由浅入深**：

1. 全样本散点、认购热度三组的收益中位数／破发率。
2. 在各季度和A+H／非A+H内重复比较；一起看发行金额与公开发售份额。
3. 若关系有经济意义且不靠少数点支撑，再做一个简单相关回归：log(1+IR)与log认购倍数，逐步增加发行规模、A+H和季度控制。最终需求与收益共同决定，解释为关联。
4. 最后再问高需求组在首日收盘之后5／20日表现如何，采用相同完整窗口样本；不直接跳到长期反转。

**补数**：基础版无需新增；精确“认购前能否预测”的问题才需要发布时间明确的孖展／暗盘资料，该预测题暂不纳入A。

**完成标准**：两张图、两张分组表、一段说明关系在哪些组稳定／不稳定；确有必要时才附一个少控制变量回归表。

### B. 高首日收益是否等于散户申购赚钱？——最值得补少量新数据

**问题**：申请一手、十手或固定预算时，平均获配多少？首日卖出期望赚多少港元？热门IPO的低配售率是否抵消上涨？

**现有数据能做**：用最终公开股数／有效申请股数得到发行人平均配售率，再算配售率×首日收益。113家可以先做基础描述，但这不是一手中签率或实际个人收益。

**关键新增数据**：一手股数、每个申请档位的申请股数／有效人数、保证配售数量、抽签人数和额外获配数量，Pool A/B以及公告页码。原始公告可能已在本地；缺的是统一的“发行人×申请档位”结构表。

**是否能得到**：可以从公开配发公告提取。已抽查 [2026-01-12公告](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0112/2026011201301.pdf)、[2026-02-10公告](https://www.hkexnews.hk/listedco/listconews/sehk/2026/0210/2026021001338.pdf) 和 [2026-04-16公告](https://www.hkexnews.hk/listedco/listconews/sehk/2026/0416/2026041602158.pdf)，都有档位、申请人数与获配／抽签规则；这证明渠道可用，尚不证明113家已全部抽取或格式一致。

**执行顺序**：先试采12家，覆盖三个季度及不同认购热度；试采只用于验证提取方法，不当作代表性结果。成功后扩到113家；无法抽取的逐家列原因。档位策略在看策略收益前固定，一手／十手各自按发行人的lot定义；固定预算策略使用不超过预算的已披露档位，并记录未用余额。

**最简单的计算**：某档位期望获配股数=保证获配数+抽签概率×额外股数；预期首日毛利润=期望获配数×（首日收盘价−发行价）。同时报告港元利润和申请本金毛收益率。由各档位分配规则检验总配售股数对账，不用全市场平均配售率代替档位数据。

**费用**：先做不扣费的基准，再列有来源的费用／融资情景。若缺历史券商费率、优惠及个人贷款记录，不能称实际账户净收益。发行人承销佣金不是投资者交易费用。

**完成标准**：可审查的档位数据表；一手／十手／固定预算的期望毛收益表；按认购热度对照。可以先形成一个清楚的问题，不必先做IV或复杂结构模型。

### C. A+H新股为什么首日涨幅较小？——第三候选，小样本专题

**问题**：H股发行价相对已有A股价格折让多少？折价深的新股首日是否涨得更多？上市后价差是否有明显变化？

**已有数据**：A+H独立标记38家，已采参考锚38家，4家缺口已补齐；其中6727保留异常旗标，实际定价日仍可能缺失。日历和汇率时点已有记录。互斥路径A+H组为36家，不能与独立标记混用。

**基础版**：先比较A+H与非A+H的发行规模、认购热度和首日收益；在有效锚样本画发行折价分布和折价—首日收益散点。用当日A价与FX明确日期，最后才看同一匹配样本的上市日到第20交易日价差。

**补数可行性**：有现成A股ticker匹配和行情采集工具，补4家属于小范围新增查询，判断为较可行；须实际返回价格／日期并核对原价后才确认完成。免费接口的历史可得性和授权不是保证，必要时查学校已有数据库权限。新增行业对照和第一公告日属于后续升级，不阻碍基础版。

**完成标准**：两张分布／散点图，一张A+H与非A+H比较表，一张日期匹配的价差表。先描述“公共价格锚”的关联，不声称A股价格是外生工具。

## 哪些选题近期移出主线

| 选题 | 当前决定 | 理由／重新启动条件 |
|---|---|---|
| 孖展羊群、融资加速、个体杠杆 | 移出近期研究 | 仅25家／93条媒体快照，缺统一调查成员和个人账户；补发布时间也不能恢复个体资金流 |
| 机制A/B的独立因果效应 | 移出近期研究 | 18C与A机制高度重叠，共同支持不足；基础全景里保留频数即可 |
| FINI／2025改革的政策效应 | 当前2026样本不做 | 缺制度前后观察；将来用户另定跨年研究才重新设计 |
| 基石认证、供给挤压的因果分离 | 延后 | 基石份额先进入描述表；认证与需求／流通盘同时变化，复杂方法不自动解决识别 |
| 解禁与稳价结束冲击 | 延后 | 契约期限／可比事件窗口、公司年龄和覆盖更复杂；先把短期表现和日期看清楚 |
| 一年／三年长期绩效 | 等待或另设历史样本研究 | 2026总体对应窗口尚未发生，不能靠补采恢复未来收益 |
| VC董事席位、保荐人网络、治理效应 | 保留题库，近期不深入 | 董事／投资者实体定义和分组较多；先研究覆盖较好的价格与需求 |
| 大量尾部回归、IV、DiD、机器学习预测 | 非起步任务 | 只有在基础结果提出明确问题、数据和识别条件成立后才选择方法 |

已有代码和结果保留用于追溯；“移出近期主线”不等于删除数据或否认已有探索。

## 补数优先顺序与执行节奏

1. **现在**：运行 `make basic-analysis`，完成全景表图和异常记录；A用现有数据起步。基础报告不用等待孖展、长窗口或跨年采集。
2. **接下来**：档位采集已扩至113家，4,582行；93家三项总数匹配，19家申请股数合计冲突，3355隔离。C的4家锚已补。先用经复核的干净档位子样本做B，并逐项处理差异，见[补数台账](../pipeline/reports/data_gap_collection/README.md)。
3. **读表后**：根据问题清晰度、数据完整度、组别大小和经济量级，在A/B/C中保持最多两条主线；未显著或关系不稳定也可以是结果，不按p值选题。
4. **最后**：为选定问题增加一个必要的简单回归／稳健性检查，写成短研究稿，再决定是否值得升级方法。

缺失数量、来源与可获取性详见 [DATA_GAPS_2026.md](DATA_GAPS_2026.md)。这是一份执行顺序，不承诺固定完成天数；公开可得与已经核实可用要分开记录。
