# 香港 IPO 制度研究：原始来源笔记

检索日：2026-10-04（香港）。范围为制度综述，不使用仓库内部样本数字代表整个市场。

- HKEX 主板财务门槛及截至2026-09-30上市申请快照：官方 [Equity Securities](https://www.hkex.com.hk/Listing/Explore-By-Role/Potential-Applicants/Equity-Securities?sc_lang=en)。三年记录；盈利测试5亿市值、最近年3500万利润、前两年4500万；现金流测试20亿市值、5亿营收、前三年合计1亿经营现金流；营收测试40亿市值、5亿营收。页面明确1–9月主板116、GEM2家新上市，不等于普通主板IPO样本。申请489/12，也不等于独立公司或已获批上市。
- [2025-08-01改革公告](https://www.hkex.com.hk/News/Regulatory-Announcements/2025/2508012news?sc_lang=en)：2025-08-04及以后刊发上市文件适用；普通IPO非基石建簿配售至少40%，A公开5%在15/50/100倍需求触发15/25/35%，B公开10%–60%不自动回拨；基石6个月锁定保留。
- [PN18现行文本](https://hkexen.thomsonreuters.com/rulebook/initial-public-offer-securities)：第3.1公开A/B池各半，申请额不超过500万/超过500万，不能重复申请；第3.2非基石配售40%，不含增量及绿鞋股份。与机制A/B不是同一A/B。第4.5不可同时从公开/配售两边获配（特定投资人例外需逐案核对）。
- [官方2025咨询总结PDF](https://www.hkex.com.hk/-/media/HKEX-Market/News/Market-Consultations/2016-Present/December-2024-Optimise-IPO-Price/Conclusions-Aug-2025/cp202412cc.pdf)：第531–536段（印刷页128–129）未采用向上调价10%提案；通常价格区间宽度没有统一限制，只有采用现行向下定价弹性机制时上限不超过下限130%。增量发行期权15%与超额配股期权15%功能不同。第181–184段及附录A+H比例分母为同类总股数（A+H），不是H股单独股数。
- [Guide 4.14 May2026 PDF](https://en-rules.hkex.com.hk/sites/default/files/pdf_documents/4.14_Offering-related_Mechanisms_202605.pdf)：搜索可识别，但web正文抓取失败，不作为唯一本体证据。通过PN18、官方咨询总结及政府答复交叉核对。
- [LCQ9 2026-05-13](https://www.info.gov.hk/gia/general/202605/13/P2026051200604p.htm)：改革后至2026年4月底109宗IPO，12宗18C，2宗机制A、95宗机制B；用作制度采用情况快照，不作改革因果效果证据。18C公开初始5%，10倍→10%，50倍→20%。
- [18C.08现行](https://en-rules.hkex.com.hk/rulebook/18c08)：至少50%由独立定价投资者认购，基石也可合资格；不是普通IPO非基石40%规则的直接替代写法。
- [18C暂时调整2024-08-23](https://www.hkex.com.hk/News/Regulatory-Announcements/2024/240823news?sc_lang=en)：商业化/未商业化40亿/80亿市值，实施期2024-09-01–2027-08-31，须核对上市及申请条件。
- [FINI launch](https://www.hkex.com.hk/News/News-Release/2023/230927news?sc_lang=en)：2023-11-22启动；定价到交易5→2营业日，新公开发售预融资模式减少锁资；不是二级市场现货交收制度的同一T。
- [基石官方FAQ](https://www.hkex.com.hk/Global/Exchange/FAQ/Top-Questions?sc_lang=en)：最终IPO价、保证分配、六个月锁定。[原GL51-13归档](https://www.hkex.com.hk/-/media/HKEX-Market/Listing/Rules-and-Guidance/Archive/Guidance-Letters/GL51_13.pdf)已整合进Guide4.15，只用来说明规则历史。
- [Rule8.08](https://en-rules.hkex.com.hk/rulebook/808)：普通初始公众比例≤60亿25%；60–300亿max(15%,15亿/同类市值)；>300亿max(10%,45亿/同类市值)，300持有人、前三大公众持有人占公众≤50%。
- [持续公众量2025-12-17结论](https://www.hkex.com.hk/News/Regulatory-Announcements/2025/251217news?sc_lang=en)：2026-01-01生效；一般替代条件10%且>10亿市值；A+H5%或>10亿市值。不能拿持续条件直接代替首次上市条件。
- [2026-07-24竞争力改革公告](https://www.hkex.com.hk/News/Regulatory-Announcements/2026/260724news?sc_lang=en)：当天生效，WVR20亿? 注意单位：HK$20bn=200亿港元；或HK$6bn=60亿港元并营收HK$600m=6亿港元。≥400亿允许20:1。所有新申请人开放非公开申请。非WVR两年第二上市路径市值100亿→60亿。允许符合普通财务门槛者使用18A/18C专门路径。报告只摘要必要部分。
- [2026-09-21第二阶段咨询](https://www.hkex.com.hk/News/Regulatory-Announcements/2026/260921news?sc_lang=en)：通知/关连/分拆交易改革，咨询截至2026-11-30，不能写成已生效。
- [HKEX Sponsor coupling2022](https://www.hkex.com.hk/News/Regulatory-Announcements/2022/220422news?sc_lang=en)、[SFC Code FAQ](https://www.sfc.hk/en/faqs/intermediaries/supervision/Code-of-Conduct/6-May-2022---Code-of-Conduct)：2022-08-05实施建簿配售行为守则；主板至少一名保荐-整体协调人提前两个月聘任，同实体或同集团关系。角色不能笼统全部叫承销商。
- [控股股东锁定Rule10.07](https://en-rules.hkex.com.hk/entiresection/1)：最初六个月一般禁售、之后六个月不能导致丧失控股地位，有例外及合规借股。原规则全库抓取，仅引用该条和不扩展推导其他门槛。
- [SFC稳定价格正式咨询结论](https://apps.sfc.hk/edistributionWeb/api/news/list-content?lang=EN&refNo=02PR130)：交易开始至截止认购或开始交易较早日期之后30天；须披露、可能根本不稳定或随时停止。上市文件通常表述公开申请截止30天，不应一律写上市后30天。
- [HKEX grey-market FAQ](https://www.hkex.com.hk/Global/Exchange/FAQ/Securities-Market/Trading?sc_lang=en)：场外、合同权利、不等于交易所订单簿。[Futu运营方条款](https://www.futuhk.com/en/support/topic2_303)：可同日买卖，L+2交收；不是T+0交收。延期取消与交易有效性按平台条件。
- [IFEC IPO risks](https://www.ifec.org.hk/web/en/investment/investment-products/stock/stock-trading/risks.page?componentID=1555380997193&submit=true)：获配量与收益不是同一概念，弱需求更易获配、孖展获零股亦可能付利息。
- [CSRC2023境外上市](https://www.csrc.gov.cn/csrc_en/c102030/c7125865/content.shtml)：2023-03-31实施直接/间接境外发行上市备案；[HKEX VIE guidance](https://en-rules.hkex.com.hk/sites/default/files/pdf_documents/gl7714_202505.pdf)限定合同安排、合法性披露。境外注册≠业务不受内地约束。
