# 2026 学术研究设计与 brainstorm

> 2026-10-02执行顺序更新：本文件保留既有探索设计和题库，不是近期任务清单。当前从基础统计开始，只选少数问题深入，见 [当前计划](RESEARCH_PLAN_2026.md) 与 [缺数清单](DATA_GAPS_2026.md)。

设计冻结于本次新增模型运行之前。既有数据与前轮结果已经看过，所有本轮检验都是探索性；本文件不是预注册，也不建立因果识别。初始设计基准为106家；当前执行样本已扩为113家2026上市IPO（Q1 38、Q2 45、Q3 30），行情截止2026-09-30。扩样不改变探索性定位。使用安装版 ipo-empirical-research（2026-09-30 修订）和 Lowry–Michaely–Volkova 理论框架。

## 本轮执行的研究

**R1：高首日收益是否等于高零售申请收益？** 理论动机是 Rock 的配售偏差，参见[原论文](https://doi.org/10.1016/0304-405X(86)90054-1)。使用公开发售最终股数 / 有效申请股数作为发行人层面平均配售率 a。报告等权 IR、配售加权 IR = Σa·IR/Σa、申请资金收益 = mean(a·IR)，三者有不同分母。模拟每家申请 HK$10,000 的毛收益；费用 0/28/88、借款比例 0/90%、年利率 0/3/6/10%、占款 2 天是明确标注的情景，不是实际借贷数据。不得用平均配售率声称一手中签概率或实际账户回报；正式 Rock 检验还需申请档位分配表和信息类型。

**R2：基石与首日收益的关联有多脆弱？** 因变量 log(1+IR)，焦点为最终基石份额（base-offer 分母）。主规格：基石 + log发行规模 + log年龄 + A+H + VC/PE + 4–6月；附加规格增加 log认购倍数，仅用于内生需求通道描述。两个规格使用最大规格的共同有限样本并检查实际发行人 IDs；运行中发现的股数单位异常（6228.HK）从本轮焦点规格隔离并保存排除记录，此补充是在结果前冻结之后发现的数据质量处理，不算事前排除。**后续状态（2026-10-02）**：PR #23已修复HDR单位，当前配售率约0.2262，6228.HK已重新进入零售与基石样本；上句隔离是历史步骤，不是当前排除规则。报告 HC3、月份 CR1、restricted wild-cluster p、G、最高杠杆；两项 HC3 焦点检验组成 Holm family。

[Cinelli–Hazlett 原论文](https://escholarship.org/uc/item/0pg6471b) 的 partial-R² 参数化用于点估计的遗漏变量敏感性：计算把点估计降至零所需的等强度 robustness value，以及两个 partial R² 各为 1%、5%、10% 的偏差。此代数使用普通 OLS 的残差尺度，不是 HC3/聚类置信区间敏感性，不能恢复因果识别。

**R3：可识别性和事件可用性。** 保存机制×18C×定价形式分组，检查有无共同支持；不在单侧缺失的 18C 格子外推机制效应。按固定截至日 2026-09-30 保存每家实际工作簿事件日期、缓存末日、完整 [-5,+5] 窗状态和六日历月成熟状态。PR #23已引入有引用和独立复核的契约限售资料，但本脚本仅读取工作簿日期，未逐项重新核验合同。完整行情不等于所有真实契约日期均已核实；超长限售与六日历月收益分别判定。

## 候选问题矩阵

| 问题 | 竞争机制与可区分预测 | 数据与设计 | 当前决定 |
|---|---|---|---|
| 零售申请收益悖论 | 高 IR 被低配售率抵消；费用吞噬收益 | 申请/分配股数齐备；档位缺失 | 执行发行人层面描述与成本边界 |
| 基石认证 vs 流通盘挤压 | 认证降低不确定性；挤压提高首日价差和换手 | 份额、日内幅度、自由流通；份额内生 | 执行遗漏变量敏感性，不宣称因果 |
| A+H 的公共信息锚 | 已有 A 价减少不确定性；分割市场保持价差 | A+H标记38家，锚38家，4家缺口已补；6727异常保留；原价/FX/事件市场模型已有实现 | 优先扩展：分离 A 市场涨幅、H 发行折价和上市修价 |
| A+H 双市场冲击 | 稀释/供给使 A 跌；融资信息改善使 A 涨 | 实际披露日、定价日、上市日可能重叠 | 需首个 H 发行公告日期及同行匹配，避免上市事件即融资因果 |
| 孖展时间轨迹 | 需求加速 vs 截止前机械集中 | 稀疏报道、调查成员未知 | 先建固定时点/同券商覆盖；不检验指数增长或羊群 |
| 孖展新增预测力 | 预定价信息 vs 预期抑价的反向选择 | 必须记录发布时刻、定价时刻 | 待可用时点核实后做嵌套预测，不作 IV |
| 机制 A/B | 回拨改善定价 vs 发行人路线自选择 | 18C 格子可能只有 A；非18C A 小 | 保留支持诊断；不以 matching 制造识别 |
| 最低申请档位 winner's curse | 更热门的 IPO 小户配售低但大户不同 | 官方 allotment 档位表 | 最值得新增数据；按固定申请档位估计策略回报 |
| 基石解禁量冲击 | 卖压 vs 消息与企业生命周期 | 合同日期、真实限售股数、完整行情 | 待成熟；按供给暴露比较，排除重叠事件 |
| 稳价结束 | 支撑撤走 vs 价格自然漂移 | 已有稳价与邻近 placebo | 加同龄匹配和资金使用披露，实际买入是内生行为 |
| 行业匹配 BHAR | 投资者情绪 vs 风险/行业特征 | 市场 benchmark 有，匹配行业股票未齐 | 采集上市前规模/行业匹配；不把当前市场 BHAR 称风险调整 alpha |
| 部分调整 | 私有信息报酬 vs 公共信息未充分纳入 | 43家区间定价、70家固定价格；固定价格不进入revision样本 | 固定上修/下修两段，样本功效不足时仅估计区间 |
| 保荐人网络与分配 | 认证 vs 客户关系配额 | 保荐人名单有，实际客户账户未知 | 先核保荐人实体与联合保荐，避免错误首名代理 |
| VC 董事席位 | 监督 vs 选择优质企业 | PR #23已应用独立复核修复；Q2仍有5家未知 | 已有修复不等于完成回归；新研究先查证据范围、未知与组别大小 |
| 市场拥挤与资金竞争 | 同期招股吸走需求 vs 热市共同冲击 | 招股日期已存储，时间选择内生 | 发行人留一同期量、假日期、前期控制；只作关联 |
| 预测能否迁移到 Q4 | 热窗口过拟合 vs 稳定质量信号 | Q1–Q3 已探索 | 保存冻结模型，Q4完整后做真正样本外验证，不调参后重用 |

## 写作与后续采集顺序

第一优先是配售档位表和有真实发布时刻的孖展记录；第二是基石/控股股东契约解禁日期及限售股数；第三是 A+H 第一公告日期与行业匹配行情。它们直接改善估计对象或识别，不只是增加变量。所有理论预期与结果相反时也应报告，保留未显著的规格；新结果不回写为“事前假说”。
