## 2. 全表通用规则（老师手册总则）

1. 公司按**上市日**排序。
2. 只用英文标点（逗号、小数点）；**公司中文名除外**，中文名填简体。
3. 日期格式与模板一致。
4. 金额换成**基本货币单位**：`HK$125.6 million` → `125600000`。
5. 百分比填**小数**：`15%` → `0.15`。认购倍数填倍数，不是小数。
6. 确认是 0 就填 `0`；数值找不到填 `NaN`；文本/日期找不到填 `NA`。**不要留空。**
7. 不确定就填 `NaN`/`NA`，不要猜，不要为了勾稽去改数字。
8. 主板和 GEM 分开存；本表只收主板。
9. 无香港公开发售、也无国际配售募资的（转板、介绍上市）**整家删除**。
10. 不要把招股书**预计值**和配发公告**最终值**混用。
11. 不要只在一边计入超额配售（绿鞋）。

每填一个数，尽量记下：公司代码、列、文件种类、URL、PDF 页码、短引文。

## 3. 浅绿 A–K｜港交所新上市报告

源文件：港交所 New Listing Report（本地可用 `NLR2026_Eng.xlsx`）。  
每家在报告里占 **(a)(b) 两行**，合并成我们表里的一行。

| 列 | 字段 | 怎么找 / 怎么填 |
|---|---|---|
| A | HKEx file# of the year | 报告当年序号。排除样本后**不要重排**。 |
| B | Stock Code | 至少四位，保留前导零，加 `.HK`。例：`06082` → `6082.HK`。五位代码不要截断。 |
| C | Company Name at time of listing | 上市时英文名。`H shares / B / W / P` 等标注按源保留。Chapter 20（投资工具）不收。 |
| D | Date of Prospectus | 招股书发布日。后面所有“招股书日前”的市场窗口都以 D 为界。 |
| E | Date of Listing | 实际上市/首个交易日。按此日排样本、分季度。 |
| F | Sponsor(s) | 保荐人全称。多个用 ` / `。同一名称折行不要拆成两家。 |
| G | Reporting Accountants | 申报会计师全称。 |
| H | Valuer(s) | 估值师。没有就 `NA`（港交所原文有时写 `N/A`，可保留）。 |
| I | Funds Raised HK (a) | 报告 **(a) 行**香港公开发售募资，HK$ 基本单位。 |
| J | Funds Raised Int.(b) | 报告 **(b) 行**国际配售募资，HK$ 基本单位。不要假设 I+J 等于招股书 M×K。 |
| K | IPO Subscription Price (HK$) | **最终发售价**。两行冲突时回查配发公告，不要用招股区间代替。 |

## 4. 浅蓝 L–CI｜招股书

### 4.1 股份结构 L–S

老师手册 2.1。主要在 **IMPORTANT** 页和 **SHARE CAPITAL**。

| 列 | 字段 | 口径 | 招股书位置 |
|---|---|---|---|
| L | Total (without option) | IPO 后总股本，**不含**超额配售/选项 | SHARE CAPITAL |
| M | Global Offering (without option) | 初始全球发售股数，不含选项 | IMPORTANT / SHARE CAPITAL |
| N | Number of offer shares under the capitalization Issue | 手册定义 = **IPO 前旧股**。不要按字面只抓红股发行量 | SHARE CAPITAL |
| O | Number of offer shares under Capitalization Rest | 手册定义 = **IPO 后仍由原股东保留的旧股** | SHARE CAPITAL |
| P | Sale Shares | 老股东在 IPO 卖掉的老股。确认没有才填 0 | IMPORTANT / SHARE CAPITAL |
| Q | New shares | 新发行股份，与 P 分开 | SHARE CAPITAL |
| R | Placing Shares | 初始国际/配售股。不要用回拨后的最终数 | IMPORTANT |
| S | Public Offer shares | 初始香港公开发售股。与 R 同口径 | IMPORTANT |

必须勾稽（同一口径、不含选项）：

```
M = R + S
M = Q + P
L = N + Q
L = O + M
```

多数情况下 P = 0，所以 M = Q，且 N = O。

### 4.2 价格 T–U

老师手册 2.2。封面、IMPORTANT、Offer Price。

| 列 | 字段 | 口径 |
|---|---|---|
| T | Maximum Offer Price | 招股书最高建议价 HK$/股 |
| U | Minimum Offer Price | 最低建议价。只披露一边时另一边填 `NaN`，不要猜。固定价可 T=U |

要求：`U ≤ T`。这是招股**区间**，不是最终定价 K。

### 4.3 上市前财务 V–AN，外加 AT–AY、AZ、BZ–CB、CF–CH

老师手册 2.3。主要在：

- SUMMARY OF HISTORICAL FINANCIAL INFORMATION
- CONSOLIDATED BALANCE SHEETS / STATEMENTS
- MD&A、INDEBTEDNESS、会计师报告附注

**期间规则：**

- year-1 / year-2 / year-3 必须是同一套历史期间。
- 只有 **year-1 的销售、税前利润、净利润** 在不足一年时才年化。
- 资产、权益、负债、现金余额、经营现金流、研发支出、资本化开发成本 **一律不年化**。
- 找不到总资产/总负债填 `NaN`，**禁止**用流动资产/流动负债代替。
- 金额用招股书披露币种，并在 V 记录币种。不要按总部所在地换币。

| 列 | 字段 | 口径 |
|---|---|---|
| V | currency in financial information | 财报币种，如 RMB / HKD / USD |
| W/X/Y | total assets year-3/2/1 | 期末总资产，基本单位，不年化 |
| Z/AA/AB | total equity year-3/2/1 | 期末总权益（含非控股权益时，要与总负债口径一致） |
| AC/AD/AE | total liability year-3/2/1 | 期末总负债 |
| AF/AG/AH | Net sales year-3/2/1 | 销售收入。AH 若不足一年，用原额 / AZ 年化 |
| AI/AJ/AK | Profit before tax year-3/2/1 | 税前利润。AK 不足一年则年化。保留亏损负号 |
| AL/AM/AN | Profit for the year year-3/2/1 | 净利润。AN 不足一年则年化。保留亏损负号 |
| AT | Year-1 financial period end | year-1 原始期末日期 |
| AU | Operating cash flow in year-1 | **经营活动现金净额**，不是经营利润，不年化 |
| AV | Cash and cash equivalents at year-1 end | 期末现金及等价物。不自动加受限现金 |
| AW | R&D expensed in year-1 | 计入损益的研发费用，不年化，不与资本化混用 |
| AX | Development costs capitalized in year-1 | **当期新增**资本化开发成本，不是期末余额。`–` / nil 填 0 |
| AY | Top 5 customers (% of year-1 revenue) | 前五大客户收入/总收入，小数。按披露的客户集团合并 |
| AZ | Comments（年化系数） | year-1 销售/利润原始期间长度。6 个月 = `0.5`，全年 = `1`。年化额 = 原额 / AZ |
| BZ | Year-1 net sales (original) | AH 年化前的原始销售额 |
| CA | Year-1 profit before tax (original) | AK 年化前原值 |
| CB | Year-1 profit for period (original) | AN 年化前原值 |
| CF | Gross profit in year-1 | year-1 毛利，原始期间，不年化 |
| CG | Capital expenditure in year-1 | year-1 资本开支，原始期间，不年化 |
| CH | Audit opinion (year-1) | Unqualified / Qualified / Adverse / Disclaimer / NA |

财务勾稽：各年 `总资产 = 总权益 + 总负债`。

### 4.4 承销 AO–AQ、上市费用 CI

老师手册 2.4。章节：

- **UNDERWRITING**
- **UNDERWRITING ARRANGEMENTS AND EXPENSES**
- **Underwriting Commission / Commissions and Expenses**

关键词：`underwriting commission of X% of the aggregate Offer Price`

| 列 | 字段 | 口径 |
|---|---|---|
| AO | Underwriting Commission (% of fund raised HK (a) | 香港侧佣金占募资比例，填小数 |
| AP | Underwriting Commission (% of fund raised Int.(b) | 国际侧，规则同 AO |
| AQ | Over-allotment Option (%) | 招股书披露的绿鞋额度，填小数。**不能默认 15%**，也不代表后来实际行使 |
| CI | Listing expenses (HK$) | 上市费用总额（港元基本单位）。这是总费用，**不能拿它当承销佣金** |

佣金填法：

- 按 **全球发售** 给比例 → AO、AP **同填**该比例。
- 只按 **香港公开发售** 给比例 → AO 填比例，AP 填 `0`。
- 只给金额、没给百分比 → 金额 ÷ 对应募资基数。

### 5.1 配发公告为主 CJ–DC、CX

公告标题通常是：  
`ANNOUNCEMENT OF FINAL OFFER PRICE AND ALLOTMENT RESULTS`

| 列 | 字段 | 怎么取 |
|---|---|---|
| CJ | Cornerstone investor names | 招股书 CORNERSTONE INVESTORS 名单，再用配发公告逐名校准。无基石填 `NA`。不要用目录/豁免段 |
| CK | Final cornerstone allocation (% of base offer) | 最终基石股数 ÷ **不含绿鞋**的最终基础发售股数。不要用承诺金额。表格汇总和子项不要重复加 |
| CL | Earliest cornerstone unlock date | 合同允许最早处置日，不是实际卖出日。公告若写“最后禁售日”，通常**次日**才是解禁日。不要固定加 180 天 |
| CM | Subscription Ratio (times) | 香港公开发售有效需求 / 初始香港公开发售股数，填倍数。必须区分 `subscribed x times` 和 `oversubscribed by x times` |
| CN | Public applicants | 有效申请人次/人数，按公告 |
| CO | Public valid applied shares | 有效申请股数 |
| CP | Public subscription original wording | 把公告原句抄下来，便于核对 CM |
| CQ | Pricing date | 最终定价日 |
| CR | Allotment announcement date | 配发公告日（可用港交所文件日期） |
| CS | Final global offering shares (before over-allotment) | 最终全球发售股，**行使扩大发售权后、绿鞋前** |
| CT | Final public offer shares | 回拨后的最终公开发售股 |
| CU | Final placing shares | 回拨后的最终配售股 |
| CV | Over-allotment shares actually issued | 后来实际行使绿鞋发行的股数；未行使填 `0`。另查 `FULL EXERCISE OF THE OVER-ALLOTMENT OPTION` 公告 |
| CW | Actual clawback / reallocation description | 回拨实际情况，抄公告描述 |
| CX | Net IPO proceeds to issuer (HK$) | 发行人所得**净**募资。排除售股股东所得 |
| CY | Public shareholding at listing (%) | 实际上市公众持股比例，不能拿法定最低比例代替 |
| CZ | Share base used for both public shareholding ratios | 写清分母股数、股类、日期、是否含选项 |
| DA | Unrestricted public shareholding at listing (%) | 无禁售限制的公众股 / 与 CY 同一分母 CZ。同基准下 `DA ≤ CY` |
| DB | Free float denominator description | 自由流通量分母口径说明 |
| DC | Free float denominator shares | 自由流通量分母股数 |

配发公告勾稽：

```
CT + CU = CS
CK = 基石股数 / CS（或不含绿鞋的 base offer）
CS ≥ M   （行使了发售规模调整权时）
最终股数 × 最终价 K ≈ 最终募资
```

### 5.2 市场与制度 DD–DO、中文名 DP

| 列 | 字段 | 来源 | 口径 |
|---|---|---|---|
| DD | HSI return over 20 trading days before prospectus (%) | 恒生指数日线 | t = 招股书日前最后一个港股交易日。`P(t)/P(t−20)−1`。要 21 个收盘价，不是 20 个自然日，也不含招股书当日 |
| DE | HK ordinary IPO count in 90 calendar days before prospectus | 港交所新上市列表 | 窗口 `[D−90, D)` 内主板+GEM 普通股 IPO。排除转板、介绍上市、后续发行；不计 D 当日 |
| DF | 1-month HIBOR before prospectus (%) | HKMA Daily Monetary Statistics | 招股书日前已公开的最近一期 1-month HIBOR，年利率填小数 |
| DG | Banking system aggregate balance before prospectus (HK$) | HKMA 同上 | 招股书日前最近一期银行体系总结余，HK$ 基本单位。不要用事后修订值 |
| DH | First trading day closing price (HK$) | 行情 | 首个实际交易日**未复权收盘价**。不是暗盘、开盘价或首日回报 |
| DI | First trading day opening price (HK$) | 行情 | 首日开盘价 |
| DJ | First trading day high (HK$) | 行情 | 首日最高价 |
| DK | First trading day low (HK$) | 行情 | 首日最低价 |
| DL | First trading day volume (shares) | 行情 | 首日成交量（股） |
| DM | First trading day turnover (HK$) | 行情 | 首日成交额（港元） |
| DN | Offer mechanism | 招股书刊发日 + 回拨安排 | 按制度版本判定，如 Mechanism A / B / Pre-reform |
| DO | Applicable IPO rules / transition basis | 同上 | 写清适用规则，例如 FINI 自 2023-11-22、新定价机制自 2025-08-04 |
| DP | Company Chinese Name | 招股书封面或公司网站 | **简体中文**。老师要求放最后一列 |

DF / DG：一张“日期 → HIBOR / 总结余”的日度表就能覆盖全部公司。对每家取**严格早于招股书日 D** 的最后一条。

## 6. 交表前 1 分钟检查

股份：`M=R+S`，`M=Q+P`，`L=N+Q`，`L=O+M`  
财务：每年 `资产=权益+负债`；`U≤T`  
佣金：全球发售同率则 AO=AP；只香港则 AP=0；CI 不是佣金  
绿鞋：AQ 看招股书额度，CV 看后来实际行使  
基石：CK 分母不含绿鞋；CJ 用真实名单  
公众持股：`DA ≤ CY`，且分母都是 CZ  
year-1 不足一年：AH/AK/AN 已年化，AZ 有年分数，BZ/CA/CB 保留原值  
空值：数是 `NaN`，字是 `NA`，确认零是 `0`
