# Security & Data Privacy Policy

## Data Privacy Guarantee

This repository is strictly dedicated to **open-source tooling, data extraction pipelines, and econometric methodologies**. 

In accordance with academic research protocol and confidentiality agreements:
- **No private research datasets, collected spreadsheets (`.xlsx`), raw prospectuses, or extracted JSON data files** are stored or tracked within this repository.
- Any attempt to commit sensitive data files is blocked by repository ignore policies.

## Reporting Security Vulnerabilities

If you discover any security vulnerabilities, pipeline bypass issues, or data exposure risks, please contact the maintainers directly through GitHub Issues or by email rather than opening a public issue with sensitive payloads.
